# NAGASHI — タクシー需要予測・集客サポートアプリ

タクシー運転手向けに「今、どこに行けば乗客を拾えるか」をリアルタイム提示するツール。
運行障害・イベント終演・天候・終電の4トリガーを統合し、需要ヒートマップとアクション提案を表示する。

## リポジトリ構成

```
├── docs/
│   └── technical-design.md   # システム構成・技術設計書 v0.1
├── prototype/
│   └── index.html            # 需要ヒートマップUIプロトタイプ(モックデータ)
└── README.md
```

## プロトタイプの動かし方

`prototype/index.html` をブラウザで開くだけで動作します(ビルド不要)。

- 下部スライダーで 18:00〜1:30 の一晩をシミュレート
- 19:30 に中央線運転見合わせシナリオが発火
- 21:00 東京ドーム終演で周辺需要がピーク
- 「☂ 雨を降らせる」トグルでオフィス街の帰宅需要を追加

技術: Leaflet + leaflet.heat / CARTO dark tiles / Vanilla JS(単一HTMLファイル)
